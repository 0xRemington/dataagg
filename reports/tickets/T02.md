## Contract rules (enforced by models, tested)

- **Time:** naive datetimes are rejected and aware ones are normalised to UTC. JSON uses ISO 8601 with `Z`. A poll's `observed_at` must equal the result's `fetch_completed_at`. `provider_event_at` is null unless the source supplies it. `quote_time_basis=provider_event` holds if and only if an event time is present. `provider_event_ns` keeps sub-microsecond digits and must agree with `provider_event_at`.
- **Numbers:**
  - Prices are `Decimal` within `numeric(20,8)`. Binary floats, NaN, infinities and booleans are rejected.
  - Canonical text drops trailing zeros (`1.50` becomes `"1.5"`), so equal values hash equally.
  - IV is a finite float. Counts are strict ints.
  - Negative and crossed quotes are **stored as observed**, never clamped.
- **Nulls:** missing values are not zero. The fake provider has both null OI and zero OI, and both null volume and zero volume. Terms, multiplier and deliverable stay null. A null deliverable explicitly does not mean 100 shares.
- **Results:** `status=empty` holds if and only if there are no rows. `partial` requires a `partial_result` failure. `complete` forbids failures, rejects and missing sides. `Coverage.scope_complete` requires `completeness_confidence=known` and all expected sides. `payload_body` must match `payload.sha256` and `byte_count`, and it is never serialised.
- **Failures:** `RateLimited(retry_after)`, `Unauthorized`, `Unavailable`, `UnsupportedCapability` and `SchemaChanged` are raised as `ProviderError` subclasses. Each carries the `RequestCounts` it consumed and serialises with `.to_failure()`. A response with some valid rows is a `partial` result, never an exception.
- **Capabilities:** every fact defaults to `unknown`. Claiming `supported` or `unsupported` requires confidence, evidence and `checked_at`. Entitlements default to unreviewed. Request limits default to null, never invented.
- **Boundary:** the domain package and the provider base/fake modules import no pandas, numpy, yfinance, sqlalchemy, psycopg or requests. A test checks this through the AST.

## Fake provider

- **Determinism:** `FakeProvider(FakeScenario(seed=...), FakeClock(start))` is a pure function of its scenario and clock. Response IDs, payload bytes and observations replay identically.
- **Parsing path:** each fetch renders synthetic JSON (representation `synthetic`) and then parses it with a versioned parser. Use `reparse_chain` to apply a parser correction to the same response.
- **Markets:** two synthetic symbols, `SYNA` and `SYNB`. Four expiries are listed: two inside 30–90 DTE, one shorter and one longer. Each chain has 12 strikes per side with calls and puts.
- **Built-in anomalies:**
  - quotes: zero bid, missing bid, locked, crossed, negative bid;
  - IV: an implausible 1250% value;
  - activity fields: null vs zero volume, null vs zero OI;
  - last trade: one stale by 10 days, one null.
- **Scripts:** per-operation steps cover rate limit with Retry-After, unauthorized, unavailable, deadline exceeded, schema drift, calls-only, puts-only, empty, malformed row, non-finite row, ambiguous OCC symbol and invalid OHLC. `bar_revisions` changes a bar from the Nth fetch onward. `omitted_minutes` drops minutes.
- **Prices:** option prices are constant within `price_epoch`, five minutes by default. Two polls in one epoch are equal-price observations with distinct response IDs and identical payload checksums.
- **Bars:** `1m` and `1d` only, closed bars only, sessions are weekdays 09:30–16:00 America/New_York with DST handled through zoneinfo. `5m`, `15m` and `4h` raise `UnsupportedCapability` without consuming a request, because they are derived locally.

## Handoff notes

- **T03 (database):**
  - Map `FetchResult.response_id` to `observation_batches.response_identity`.
  - Map `payload` to `payload_objects`. Use `representation` and `parser_version` as given.
  - Map `OptionObservation` to `option_snapshots`. Resolve `contract` to UUIDs through `contract_identifiers`. Leave `terms=None` as no `contract_terms` row; do not insert a guessed one.
  - Use `canonical_sha256()` for `content_sha256`.
  - Persistence must add `known_at` and `recorded_at`. The domain models deliberately do not carry them.
  - Store `provider_event_ns` exactly.
- **T04 (calendar):** the fake's weekday session helper is internal (`_sessions`) and must not be reused as a calendar. Collectors should use T04 for expected minutes. The fake has no holidays or early closes, so calendar fixtures must come from T04.
- **T06 (Yahoo):**
  - Mirror the fake's parse path.
  - Convert floats with `Decimal(str(x))` before building models, because floats are rejected on purpose.
  - Map NaN/NaT to `None` only where the field is optional and absence is the honest meaning. Otherwise put the row in `rejected` as `non_finite`.
  - Keep `provider_event_at=None` and `quote_time_basis=unknown`.
  - Use `Confidence.DOCUMENTED` or `Confidence.OBSERVED` with evidence for each capability, and leave the rest unknown.
  - Raise `SchemaChanged` on missing required columns.
