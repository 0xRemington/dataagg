## A07 drill

1. Populate a disposable stack: chains with retained payloads, minutes, derived bars, a pinned export and an archived month.
2. Take an encrypted backup to a separate off-host directory.
3. **Drop the source database and delete the stack's data root.**
4. Restore into `marketagg_test_dr_*` with a new storage root. During the restore, outbound sockets are refused except to the local PostgreSQL server.
5. Validate the restored instance:
   - `/health/ready` returns 200;
   - the pinned manifest resolves, and a rerun reproduces its dataset hash and file checksums;
   - archived 1m reads match the pre-backup reads;
   - RPO equals the backup snapshot's maximum known time.

A second test checks that a backup with one corrupted archive object is refused **before** any target database is created.
